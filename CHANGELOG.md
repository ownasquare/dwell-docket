# Changelog

All notable changes are recorded here.

## 0.1.0 - 2026-07-27

### Added

- One-screen, browser-local stop CSV workflow.
- Deterministic detention and proof-gap classification.
- Downloadable reconciliation docket.
- Friendly validation for file type, file size, missing headings, and invalid
  rows.
- Automatic light and dark appearance with responsive phone, tablet, and
  desktop layouts.
- Node unit tests, Playwright E2E coverage, axe scans, dependency audit, secret
  scan, license audit, formatting, lint, and type checks.
